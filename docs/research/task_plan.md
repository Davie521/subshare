# 全球订阅服务大全 — 调查计划

## 目标
全面调查并整理全球所有主要订阅服务，按类别分类，覆盖各主要市场（北美、欧洲、亚太、拉美、中东/非洲）。

## Phase 划分

### Phase 1: 影音娱乐类 ✅
- 视频流媒体（Netflix, Disney+, HBO Max, 等）
- 音乐流媒体（Spotify, Apple Music, 等）
- 播客/有声书（Audible, 等）
- 直播/短视频平台会员
- 体育赛事订阅

### Phase 2: 软件与生产力工具 ✅
- 办公套件（Microsoft 365, Google Workspace, 等）
- 设计工具（Adobe CC, Figma, Canva, 等）
- 开发工具（GitHub, JetBrains, 等）
- 项目管理（Notion, Asana, 等）
- AI/大模型服务（ChatGPT Plus, Claude Pro, 等）
- 安全/VPN（NordVPN, 1Password, 等）

### Phase 3: 云服务与基础设施 ✅
- 云计算（AWS, Azure, GCP）
- 云存储（Dropbox, iCloud, Google One）
- CDN/域名/托管
- 数据库/后端服务

### Phase 4: 游戏 ✅
- 主机游戏订阅（Xbox Game Pass, PS Plus, 等）
- PC 游戏订阅
- 移动游戏订阅（Apple Arcade, Google Play Pass）
- 云游戏

### Phase 5: 新闻、媒体与阅读 ✅
- 报纸/新闻（NYT, WSJ, 等）
- 杂志
- 电子书/漫画
- 学术/研究

### Phase 6: 教育与学习 ✅
- 在线课程（Coursera, Udemy, 等）
- 语言学习（Duolingo, Babbel, 等）
- 编程学习
- K-12/儿童教育

### Phase 7: 健康与健身 ✅
- 健身APP（Peloton, Strava, 等）
- 冥想/心理（Calm, Headspace, 等）
- 营养/饮食追踪

### Phase 8: 生活方式 ✅

### Phase 11: 出行与交通 ✅
